# You'r'Cooked assets

Dépose ici tous les médias spécifiques au mini-jeu `You'r'Cooked`.

Sous-dossiers suggérés :

- `backgrounds/` : arrières-plans (ex : `lvl1.png`).
- `stands/` : sprites des stands, machines et comptoirs.
- `ingredients/` : icônes des aliments, portions et casseroles.
- `player/` : sprites ou animations du cuistot.

Ajoute librement d’autres sous-dossiers (sons, particules…) selon les besoins.
